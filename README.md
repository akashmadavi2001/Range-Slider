# Range-Slider

The Custom Range Slider is an interactive frontend web project that allows users to select and adjust a numeric value using a visual slider.

The slider provides a range from 0 to 200, with the currently selected value displayed dynamically as the user moves the slider. This creates a simple and user-friendly way to select values without manually entering numbers.

Key Features
Interactive range slider from 0 to 200
Real-time value selection
Smooth and responsive user interaction
Clean and minimal user interface
Easy-to-use control for selecting numerical values
Built using frontend technologies such as HTML, CSS, and JavaScript
How It Works

The user can drag the slider handle from left to right to change the value. As the handle moves, the selected number updates automatically. JavaScript handles the slider interaction and dynamically reflects the selected value on the webpage.

Purpose

This project demonstrates how to create and customize an interactive range input component using frontend development techniques. It can be used as a foundation for applications such as price filters, volume controls, percentage selectors, product filters, and other interfaces that require numerical input.
